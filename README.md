# Open WebUI on Roar AI

The template behind **Launch Open WebUI** in the Roar AI console. It is one line: the
official Open WebUI image (slim build), at a tested version.

Everything else is set by the platform when the app is created: a database for chats,
users and document search, file storage for uploads, a sign-in key kept in your app's
own variables, and your Roar AI models already connected — chat, document search,
voice input and read-aloud.

You do not need to fork this repository to use Open WebUI on Roar AI.
